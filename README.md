# nutrition_bot

Telegram-бот, который считает калории и БЖУ по фото блюда и ведёт дневник питания.
Предшественник [foodaibot](https://github.com/jacurlive/foodaibot).

## Что делает
- Распознаёт блюдо на фото через GPT-4o vision и возвращает калории, белки, жиры, углеводы
- Позволяет поправить порцию (граммы) перед сохранением
- Ведёт дневник по дням с навигацией
- Личная цель (похудение / поддержание / набор) и дневные нормы по возрасту, росту, весу
- Утренняя сводка, языки: узбекский, русский, английский
- Команда `/stat` для администратора

## Стек
Python, aiogram 3 (FSM), Django 5 + DRF, OpenAI API (GPT-4o), SQLite/PostgreSQL

## Архитектура
```
Telegram ──► aiogram-бот (FSM, i18n) ──HTTP──► Django REST API ──► БД
                  │                              пользователи, дневник, приёмы пищи, нормы
                  └──► OpenAI GPT-4o vision (фото → структурированные данные о питании)
```
- Бот — тонкий клиент; пользователи, дневник и настройки живут в Django-бэкенде.
- AI-вызов изолирован в одной функции (`фото + язык → структурированный результат`), модель или провайдера легко заменить.
- Поток «превью → правка → сохранение»: неверное распознавание не попадает в дневник.
